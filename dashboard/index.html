🌐 Google Sheets

Conecta o painel a uma planilha LEDS Urbs online, com atualização em tempo real (a cada 15 s, 30 s ou 60 s).
Aceita o link normal (/d/…), a planilha publicada para a web (/d/e/…/pub — Arquivo → Compartilhar → Publicar na web) ou o ID puro. Formato igual ao "Leds Urbs": aba LEDS com as 16 telas.
⚠️ O Google bloqueia a conexão quando o painel é aberto direto do arquivo (file://) — erro "Failed to fetch". Abra sempre pelo iniciar.bat (http://localhost:8000/dashboard/).
Sem a chave, usa conexão pública (gviz). Com a chave, usa a Sheets API v4 (permite planilha privada).
Nenhuma conexão ativa. Cole o link e clique em "Conectar".
